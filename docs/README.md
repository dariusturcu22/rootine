# Rootine documentation

All documentation is written in English, in simple words.

| Folder / file | What is there |
|---|---|
| [architecture/overview.md](architecture/overview.md) | Components, how they talk, ports, diagram |
| [decisions/](decisions/) | Architecture Decision Records (ADRs): why we chose what we chose |
| [api/](api/) | API contract between the parts. Read [api/README.md](api/README.md) first |
| [sprints/](sprints/) | One short file per sprint |
| [meetings/](meetings/) | Meeting notes, one file per meeting (`YYYY-MM-DD.md`) |
| [product/](product/) | Branding, marketing and monetization notes |

Setup and run instructions are not here. They are in [../SETUP.md](../SETUP.md).
